markdown常用语法记录

2020-05-17
笔记
markdown

标题 ​

语法：#号后面加一个空格，再输入内容。

示例：

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题

按#的数量区分标题的级别，如果嫌一级标题过大可以直接从二级标题开始，在正文中一般都是使用二级标题到四级标题，能够满足大部分需求。

代码 ​

如果要在文章中将内容表示成代码形式，单词或短语可以使用 ` 将需要转化的内容包裹起来。

示例：

`code`

而如果你的代码内容很长，那么可以使用代码块。要创建代码块可以使用三个连续的 `，中间区域放置对应的代码内容，最后再以三个同样的符号进行结尾即可。

示例:

```
代码
```

图片 ​

在markdown中插入图片非常简单，只需要以！开头在后面的[]中输入图片的名称最后在()中填写图片的链接或地址即可。

示例：

![图片名称](图片链接)

链接 ​

链接的语法如下：

[链接的描述](链接)

脚注 ​

所谓的脚注，就是对读书所做的笔录、见解、体会、看法、观点、心得、感想的总称，亦或是引用文献的注释等。

在中的脚注语法分为两种。一种是分成两部分，放在正文中的 [^编号] 和放在文末的 [^]:

示例：

正文部分：需要注释说明的文字[^1]
[^1]:解释说明。

正文部分：需要注释说明的文字[1]

而另一种则是直接在需要注释的文字之后使用。

示例：

正文部分：需要注释说明的文字[^解释说明]

正文部分：需要注释说明的文字[^解释说明]

第二种使用方法可能部分主题或软件不支持，通常使用的是第一种。

列表 ​

有序列表可以使用数字 + 句点 + 空格 + 文字的语法进行创建。

如：

1. 第一段
2. 第二段
3. 第三段
  1. 第一段
  2. 第二段
  3. 第三段

无序列表的语法则是-号或+号 + 空格 + 文字的形式。

如：

- 列表1
- 列表2
- 列表3

+ 列表1
+ 列表2
+ 列表3
  • 列表1
  • 列表2
  • 列表3
  • 列表1
  • 列表2
  • 列表3

当然你也可以对列表进行嵌套，像这样：

- 此处为1个“-”号+空格+文字
  1. 此处为2个空格+数字+文字
  2. 此处为2个空格+数字+文字
  3. 此处为2个空格+数字+文字
  • 此处为1个“-”号+空格+文字
    1. 此处为2个空格+数字+文字
    2. 此处为2个空格+数字+文字
    3. 此处为2个空格+数字+文字

多层示例：

- 此处为1个“-”号+空格+文字
  - 此处为2个空格+“-”号+文字
   - 此处为3个空格+“-”号+文字
  • 此处为1个“-”号+空格+文字
    • 此处为2个空格+“-”号+文字
    • 此处为3个空格+“-”号+文字

如上所属，你可以根据自己的需求进行调整，嵌套不同的列表样式。

分隔符 ​

分隔符一般用来区分不同的内容区域，使用连续的+或-进行语法标注，在语法的上下行需要进行空行。

示例：


----------

删除线 ​

不同主题的删除线显示形式不同。

示例：

~~删除~~

删除

引用 ​

要引用内容，需要在段落前添加一个 > 符号。

> 这是一段引用内容

这是一段引用内容

引用内容也可以进行嵌套，只需要在要嵌套的段落前添加一个 >> 符号

> 这是一段引用内容
>
>> 这是一段嵌套引用内容

这是一段引用内容

这是一段嵌套引用内容
