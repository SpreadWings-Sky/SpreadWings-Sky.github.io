数据结构栈线性表队列

栈 ​

定义 ​

栈也是一种线性表不过是一种特殊线性表

栈（stack）是只允许在一端进行插入或删除操作的线性表

重要术语 ​

  • 栈顶：允许插入和删除的一端（最上面的元素称为栈顶元素）
  • 栈底：不允许插入和删除的一端（最底部的元素称为栈底元素）
  • 空栈：栈里没有数据元素（既线性表的空表）

进栈顺序：a1->a2->a3->a4->a5

出栈顺序：a5->a4->a3->a2->a1

特点：先进后出 Last in First Out(LIFO)

基本操作 ​

InitStack(&s): 初始化栈，构建一个空栈s，分配内存空间

DestoryStack(&L):销毁栈，销毁并释放栈s所占的内存空间

Push(&S,x):进栈，若栈S未满，则将x加入使之成为新栈顶

Pop(&S,&x):出栈，若栈S非空，则弹出栈顶元素用x返回

删除栈顶元素

GetTop(S,&x):读取栈顶元素。若栈S非空，则用x返回栈顶元素

不删除栈顶元素

StackEmpty(S) :判断一个栈是否为空

顺序栈 ​

用顺序存储的方式实现栈

栈的大小不可变

定义 ​

c
#define MaxSize 10 //定义栈中元素的最大个数
typedef struct{
    ElemType data[MaxSize]; //静态数组存放栈中元素
    int top;   //栈顶元素位置
}SqStack;

初始化 ​

初始化时可以使top指针指向栈顶位置-1，也可指向下个可插入位置0，不同的初始化后续操作也有差别

注意区分使用时不同初始化的操作

c
//初始化栈
void InitStack(SqStack *S){
    S->top = -1; //初始化栈顶指针
}
void testStack(){
    SqStack S;
    InitStack(&S);
    //后续操作...
}

判空 ​

c
//判断栈是否为空
_Bool StackEmpty(SqStakc S){
    if(s.top == -1) return true;//为空
    return false; //不为空
}

进栈操作 ​

c
//初始化top为-1时
_Bool Push(SqStack *s,ElemType e){
    if(S->top == MaxSize -1) return false;//栈满
    S->top = S->top+1; //指针先加一
    S->data[S->top] = e; //新元素入栈
    //S->data[S->++top] = e;
    return true;
}
//初始化top为0时
_Bool Push(SqStack *s,ElemType e){
    if(S->top == MaxSize -1) return false;//栈满
    S->data[S->top] = e; //新元素入栈
    S->top = S->top+1; //指针加一
    //S->data[S->top++] = e;
    return true;
}

出栈操作 ​

c
//初始化top为-1时
_Bool Pop(SqStack *s,ElemType e){
    if(S->top == -1) return false;//栈空，报错
    //e = S->data[S->top--];
    e = S->data[S->top]; //出栈
    S->top--; //指针减1
    return true;
}
//初始化top为0时
_Bool Pop(SqStack *s,ElemType e){
    if(S->top == -1) return false;//栈空，报错
    //e = S->data[S->--top];
    S->top--; //指针先减1
    e = S->data[S->top]; //出栈
    return true;
}

共享栈 ​

即两个栈共享同一片内存空间（可以节省内存空间）

c
#define MaxSize 10
typedef struct{
    ElemType data[MaxSize];
    int top1;
    int top2;
}SHStack;
//初始化
void InitStack(SHStakc *S){
    S->top1 = -1;
    S->top2 = MaxSize;
}

插入元素时栈1从底部开始，依次递增；栈2从顶部开始，依次减少**（两个栈从两边从中间增长）**

判断栈满的条件就是top1+1 = top2

链式栈 ​

用链式存储实现栈

回顾之前的单链表，我们使用头插法插入元素，然后规定只能对头结点后一个元素进行操作，即对应栈的出入栈

定义 ​

c
typedef  struct LinkNode{
    ElemType e;    //数据
    struct LinkNode *next;//指针
}*LiStack; //栈类型的定义

初始化 ​

两种实现方式（带头结点和不带头节点）

基本操作 ​

创（初始化）、增（入栈）、删（出栈）、查（获取栈顶元素）、判空、判满
