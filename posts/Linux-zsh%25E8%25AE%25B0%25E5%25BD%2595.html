Linux-zsh记录

2023-03-11
笔记
Linux

关于系统 ​

我使用的Linux系统是Ubuntu

安装过程 ​

安装zhs ​

我这边直接是从发行版的源进行安装

运行下面的命令

shell
  sudo apt-get update
  sudo apt-get install zsh

安装插件和主题 ​

目前我只使用了2个插件，目前感觉够用了

zsh-autosuggestions： 这个是自动建议插件，自动提示后续命令。

zsh-syntax-highlighting：这个是代码高亮插件，方便查看各行命令。

主题使用的是

zsh-theme-powerlevel9k 个人觉得这个主题挺简介好看的，可以显示当前路径、时间、命令执行结果，而且支持 git 分支显示等功能。

在终端中输入下列命令进行主题和插件的安装

shell
sudo apt-get install zsh-autosuggestions zsh-syntax-highlighting zsh-theme-powerlevel9k

等待运行结束，主题和插件就安装完成了

设置默认Shell并配置主题和插件 ​

更换默认Shell ​

shell
chsh -s /usr/bin/zsh

然后注销并重新登录，就启用zsh为默认Shell了。

第一次进入zsh会自动出现配置界面，在这个界面可以按自己的需要自定义需要的设置

配置主题和插件 ​

zsh 的配置文件是 ~/.zshrc 文件，这个文件在你的用户目录下 ~/

打开这个文件，将下列代码添加到其中，保存退出

这样就启用了插件和主题，我使用的是插件默认配置，有额外需求可以自行研究修改

text
source /usr/share/powerlevel9k/powerlevel9k.zsh-theme
source /usr/share/zsh-autosuggestions/zsh-autosuggestions.zsh
source /usr/share/zsh-syntax-highlighting/zsh-syntax-highlighting.zsh

配置完成后就可以愉快的使用zsh了！ ​

使用问题解决 ​

问题描述 ​

在使用zsh时遇到了

zsh: command not found: ll

的错误提示

解决方式 ​

添加环境变量配置

shell
vim ~/.bash_profile

在文件中添加

alias ll='ls -alF'

保存并退出后，重新加载文件

shell
source ~/.bash_profile

再次使用ll命令，发现运行正常
